- 🧠 Local-LLM pipelines and **RAG systems** with Ollama, llama.cpp, FAISS, ONNX
- 🎸 **Audio DSP** and real-time audio on mobile, with two Android apps shipped
- 🛠️ Ex-SAP consultant: SQL Server → SAP HANA migration, C# automation tooling
- 🎓 Starting a B.Eng in **Data Engineering & AI** at Turku UAS, Finland, in Jan 2027
- 📍 Open to backend / AI-integration roles in **Turku & Helsinki** (on-site, hybrid, remote)

C++ was my first language, I studied compilers for fun, and I had 27+ repos before LLMs existed.
